# Публикация портфолио

Публикация сейчас отложена: дизайн и анимации проверяются локально на http://127.0.0.1:4321/. Инструкции ниже предназначены для будущей публикации.

## GitHub Pages

Репозиторий: `onewaez/onewaez.github.io`. Адрес сайта: https://onewaez.github.io/.

В GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Workflow из `.github/workflows/deploy.yml` устанавливает зависимости, проверяет проект, собирает сайт и публикует папку `dist/` после каждого push в `main`.

Состояние публикации видно на вкладке **Actions**. Если проверка или сборка завершится ошибкой, новая версия не публикуется: исправьте ошибку из лога и отправьте следующий commit.

## Любой статический хостинг

На компьютере с Node.js 24:

```sh
npm ci
npm run build
```

Загрузите **содержимое** папки `dist/` в корневую папку сайта на хостинге. `index.html` должен находиться в корне, рядом с `_astro/`, изображениями и остальными файлами. На сервере Node.js не нужен.

Для получения ZIP-архива (нужен Python 3):

```sh
npm run package
```

Готовый архив: `artifacts/waez-portfolio.zip`. Он содержит готовый сайт, без исходников и `node_modules`. Хостинг должен поддерживать раздачу обычных HTML/CSS/JS-файлов и HTTPS. Специальные перенаправления для SPA не нужны.

Для быстрой проверки переноса:

```sh
python3 -m http.server 8080 --directory dist --bind 127.0.0.1
```

Откройте http://127.0.0.1:8080/. Локальный сервер нужен только для проверки. Опубликованный сайт работает независимо от вашего компьютера.

## Другой домен

Если меняете основной адрес сайта, обновите `site` в `astro.config.mjs`, canonical и Open Graph URL в `src/pages/index.astro`, адрес в `public/sitemap.xml` и `public/robots.txt`. Пересоберите сайт. Все файлы сборки рассчитаны на размещение в корне домена.

Для размещения в подпапке потребуется задать `base` в конфигурации Astro и добавить этот префикс к путям публичных ресурсов. Сборка по умолчанию предназначена для корня домена.

## Новый проект

Добавьте Markdown-файл в `src/content/projects/`, задайте следующий уникальный `order`, добавьте изображения в `public/projects/` и отправьте изменения в GitHub. Порядок: старые проекты → новый проект → About → Contact. Формат описан в README.md.
